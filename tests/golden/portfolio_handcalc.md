## Weight clock (P3, no-lookahead)

Weights decided at a decision-date close apply to returns **strictly after**
that close (`shift(1)` direction). Weights drift between rebalances:

```
r_p[t]   = sum(w[i,t-1] * r[i,t])
NAV[t]   = NAV[t-1] * (1 + r_p[t])
w[i,t]   = w[i,t-1] * (1 + r[i,t]) / (1 + r_p[t])   # drift
```

At each rebalance close, weights reset to 1/5 for the next period.

**Initial weights** at close(2024-12-31): all 1/5. (Formation default:
fully invested from `NAV_0`; ruling 1A makes ranking a no-op.)

## Metrics (P4)

### total_return

```
total_return = prod(1 + r_p[t]) - 1,  t = 0..56
             = NAV_final / NAV_0 - 1
             = 1.030011 / 1.0 - 1
             = 0.030011
```

Window compounded return, **not** annualized. The 10–15% annualized band
is step 5's gate.

### sharpe

```
sharpe = mean(r_p) / std(r_p, ddof=1) * sqrt(252)
       = 1.226090
```

rf = 0. ddof = 1 (sample std). Annualized via sqrt(252).

### mdd

```
peak_t = running max of NAV, including NAV_0 = 1.0
mdd    = min(NAV_t / peak_t - 1)
       = -0.031653
```
